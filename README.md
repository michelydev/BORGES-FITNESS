# 🏋️ Academia Borges

Site institucional desenvolvido para a Academia Borges com foco em apresentar os serviços, estrutura e formas de contato da academia de maneira moderna, responsiva e visualmente atrativa.

## ✨ Funcionalidades

- Página inicial com imagem de fundo
- Seção “Sobre” apresentando a academia
- Cards de serviços
- Área de horários
- Galeria de imagens
- Contatos clicáveis
- Design responsivo para mobile
- Animações e efeitos visuais suaves

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome

## 🎯 Objetivo do Projeto

O projeto foi desenvolvido como atividade de extensão universitária do curso de Análise e Desenvolvimento de Sistemas, buscando aplicar conhecimentos de desenvolvimento web em um projeto real voltado para a comunidade local.
